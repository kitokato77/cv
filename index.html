Center Window Reborn

C# .NET Windows API

Center Window Reborn is an ultra-lightweight, trayless C# utility designed for Windows operating systems. It provides a seamless way to instantly center the currently active application window on the monitor using a simple global hotkey (Ctrl + Alt + C). It completely removes the need for tedious manual window dragging.

Technical Details & Benefits

  • Zero UI Overhead: Runs silently in the background without any visible graphical user interface, ensuring minimal RAM consumption and absolutely no distractions.
  • Improved Stability: As the "reborn" version of an earlier Python script, this C# implementation has been highly optimized to prevent crashing and bugs related to Windows Peek (Win+,) and shell previews.
  • Smart Window Detection: Intelligently ignores the desktop, taskbar, and common system shell classes, reading the active window's rectangle and strictly moving it to the exact center of the monitor's working area without altering its z-order or resizing it.
  • Self-Contained Deployment: Capable of being published as a tiny, single-file executable using the .NET CLI.

Game Optimizer

C# WinForms Optimization

GameOptimizer is an ultra-lightweight, zero-bloatware Windows application built with C# WinForms. It is engineered to automatically maximize gaming performance by aggressively lowering the CPU priority of resource-hungry background applications whenever a favorite game is launched.

How It Works

  • Smart Auto-Optimization: Sits stealthily in the System Tray and scans for running games every 5 seconds. When detected, it forces heavy background apps (Web Browsers, Chat clients like Discord, Game Launchers, Cloud Syncs) into an Idle/Low CPU priority state.
  • Seamless Restoration: The moment you close the game, the utility intelligently detects the state change and instantly restores all affected background apps back to their normal priority, preventing system instability.
  • Process Picker & Customization: Add games easily by selecting from currently running processes (which extracts the native .exe icon) or browsing manually. Custom game lists are securely saved locally.
  • Zero Telemetry: Weighing in at only ~100KB, it consumes virtually zero RAM and relies on native Windows scheduling without any annoying pop-ups or gimmicky UI animations.

Math Blaster

JavaScript HTML5 Canvas Game Dev

Math Blaster (formerly known as "Doom JS", with the tagline Linear Algebra Protocol) is a retro-styled First-Person Shooter (FPS) in order to educational about mathematics and built completely from scratch using purely Vanilla JavaScript and the HTML5 Canvas API. It recreates the nostalgic pseudo-3D magic of 90s classics like DOOM and Wolfenstein 3D without using modern 3D frameworks like Three.js.

Technical Implementation

  • Custom Raycasting Engine: Visuals are generated dynamically per frame. The engine "shoots" rays out of the player's FOV, calculating intersections against a 2D map grid using raw trigonometry to scale vertical walls and render a convincing 3D perspective with depth shading.
  • Responsive & Cross-Platform: Features comprehensive desktop controls (WASD, Arrows, Space) and an intuitive On-Screen D-Pad overlay for mobile web browsers.
  • Procedural ZzFX Audio: Sound effects (gunshots, monster damage, power-ups) are generated mathematically on-the-fly using the ZzFX micro-synth library, keeping file sizes incredibly low while delivering authentic 8-bit crunch.
  • Advanced Systems: Includes a fully functional Heads-Up Display (HUD), 9 switchable weapon/ammo types, continuous level progression, collision detection, and a local Highscore Leaderboard system wrapped in a CSS-driven Glitch aesthetic.

Arah Jam Dua

Game Dev Interactive

Arah Jam Dua is an interactive slice-of-life Visual Novel developed with the Ren'Py Engine, set against the backdrop of an Informatics Engineering department. The game's title, which translates to "Two O'Clock Direction," references the clock face method commonly used to provide spatial orientation and directional cues to the visually impaired.

Narrative & Gameplay Mechanics

  • Immersive Storyline: Play as Irham, a final-year student rushing for a lab assistant interview, whose life changes after an unexpected encounter with Areta, a calm and observant blind girl.
  • Dynamic Point System: Your dialogue choices directly affect three distinct parameters: Interview Points (academic success), Knowledge Points (understanding of visual impairment assistance), and Affection Points (emotional bond).
  • Multiple Endings & Branching Paths: Explore various campus locations (Canteen, Labs, Educational Plaza). Your accumulated points dictate the storyline branch and the quality of the visual CGs (Good, Neutral, or Bad endings).

This project beautifully highlights themes of empathy, inclusive communication, and the importance of understanding the daily experiences of people with disabilities.

AR Paper Toss - Game Daur Ulang Sampah

Game Dev Augmented Reality Unity

An interactive, web-based Augmented Reality (AR) application designed to educate players about waste sorting through an engaging "Paper Toss" gameplay loop. This project is built entirely on free and open-source technologies, eliminating the need for any app installation as it runs directly in mobile browsers.

Key Features

  • Image Tracking AR: Utilizes MindAR to scan physical markers/stickers, which seamlessly spawns three virtual trash bins into the real world.
  • Realistic Physics Engine: Employs A-Frame Physics System (CANNON.js) to simulate realistic paper throwing mechanics affected by gravity and angle.
  • Interactive Scoring: Features a dynamic scoring system that awards points (10 points per successful throw) when players correctly toss paper into the Organic (Green), Non-Organic (Red), or Paper (Blue) bins.
  • High Accessibility: Fully mobile-friendly and highly accessible, requiring only a WebGL-capable browser (Chrome, Safari, Firefox) and camera permissions.

The project serves as a compelling demonstration of environmental education merging with modern WebAR capabilities.

Dungeon Crawler DAG

Game Dev Algorithms

Welcome to Dungeon Crawler, a robust 2D pixel-art game built from scratch using Python and the Pygame library. This game thrusts players into the role of a brave adventurer battling through procedurally generated dungeons, combining classic roguelike mechanics with advanced algorithmic level progression.

Core Systems & Algorithms

  • DAG Level Progression: The world map is structured as a Directed Acyclic Graph (DAG) navigated via Breadth-First Search (BFS). Players must unlock specific dungeons based on predefined hierarchical dependencies before progressing to the boss.
  • A* Pathfinding AI: Enemies utilize advanced A* pathfinding (with Manhattan Distance Heuristic) to intelligently navigate procedural layouts, avoiding walls to chase or ambush the player.
  • Rich Combat & Loot Mechanics: Features both melee and ranged enemies, projectile mechanics for both the player and mobs, treasure collection, and an experience-based leveling system.
  • Immersive Audiovisual Feedback: Includes dynamic UI highlights, health bars, background music for different states (Map vs. Battle), and satisfying sound effects for shooting and looting. Gamepad support (Xbox/PS5) is also fully integrated.

Start Scheduler App

Utility Automation

Start Scheduler is a comprehensive Python application designed to intelligently manage and execute applications during Windows startup using a sequential queue system. It prevents the system freeze commonly caused by dozens of apps attempting to load simultaneously on boot.

Key Capabilities

  • Sequential Queue System: Launches executables one by one, continuously checking processes and waiting until the current application has successfully started before firing the next in the queue.
  • User-Friendly Tkinter GUI: Features a drag-and-drop enabled graphical interface to easily add, remove, and reorder (set priority for) startup applications.
  • Flexible Configuration: Allows precise tuning of the delay timer between app launches and the background check intervals. All settings are auto-saved to a robust config.json file.
  • Windows Registry Integration: Registers itself directly to the Windows Startup sequence (HKCU\SOFTWARE\Microsoft\Windows\CurrentVersion\Run) with a single click inside the app.
  • Multi-Language Support: Includes seamless UI translation supporting both English and Bahasa Indonesia.

Desktop Watch

Utility UI

Desktop Watch is a sleek and unobtrusive WPF (Windows Presentation Foundation) desktop widget that persistently displays the live time, localized Indonesian date, current weather, and national holiday status directly on your desktop wallpaper.

Features & Capabilities

  • Real-Time Weather Integration: Automatically fetches weather data every 30 minutes via the Open-Meteo API (requiring no API key), complete with an offline fallback that relies on locally cached data if the internet disconnects.
  • National Holiday Syncing: Pulls live national holiday data from libur.deno.dev to keep you informed of upcoming red-letter days.
  • Global Shortcuts & Customization: Effortlessly snap the widget to 6 different screen positions (Top/Bottom and Left/Center/Right) using Shift + 1..6, change your city (Shift + L), or toggle Windows autostart (Shift + S).
  • Persistent Configuration: Automatically saves its position, chosen city, and latest weather cache locally in %LOCALAPPDATA%, maintaining state perfectly across reboots.
